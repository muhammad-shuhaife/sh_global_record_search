ODOO 20 MODULE

Global Record Search

One shortcut. Every record. Search the whole database from Odoo's built-in Ctrl+K command palette.

Features

🔍

Search every model

Covers every model reachable through a menu the user can access.

🚫

Exclude models

Skip heavy or noisy models such as logs.

➕

Add search fields

Search extra fields per model, like a product barcode.

⭐

Set priority

Important models are searched and shown first.

🔒

Secure

Respects user access rights and the active company.

⚡

Fast

Batched search with highlighted matches and "See all" links.

How to use

1

Press Ctrl+K anywhere in Odoo.

2

Type 3 or more characters.

3

Pick a result under Records, or choose See all.

⚙️ Configuration

Administrators open Settings > Global Search to exclude models, set priority and add extra search fields.

📦 Requirements

Odoo 20 Enterprise. Depends on web and web_enterprise.
