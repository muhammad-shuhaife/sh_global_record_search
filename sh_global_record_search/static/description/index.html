Global Record Search

One shortcut. Every record.

Search accessible business records from Odoo's built-in Ctrl + K command palette.

Features

Find records faster and configure the search to suit your workflow.

01. Search accessible models

Find records across models reachable through menus you can access.

02. Exclude models

Keep results focused by excluding noisy or heavy models, such as logs.

03. Add search fields

Search additional fields per model, including product barcodes.

04. Set model priority

Choose which models are searched and displayed first.

05. Respect access rights

Search follows user access rights and the active company.

06. Find results faster

Use batched search, highlighted matches and See all links.

How to use

  1. Open the palette. Press Ctrl + K anywhere in Odoo.
  2. Enter your search. Type 3 or more characters.
  3. Open a record. Pick a result under Records, or choose See all.

Configuration

Administrators: open Settings > Global Search to exclude models, set priority and add extra search fields.

Requirements

Odoo 20 Enterprise.

Dependencies: web and web_enterprise.
